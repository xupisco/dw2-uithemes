UI Themes - changelog

0.4.0 (2026-11-25)
- Dividers between the top-left section tabs, the top-right game buttons and the
  bottom-right map buttons now follow the theme (they stayed light gray).
- The outline around a section's sub-tabs (Exploration, Military...) can have
  its own color; Basalt, Graphite and Obsidian use a quiet gray instead of the
  accent.
- New theme keys: EmpireSectionList.ForeColor, AngledButtonStrip.ForeColor,
  MapOverlayButtons.DarkColor, SectionHeaderPanel.OutlineColor. Also in the
  theme editor.
- Works with Settings Keeper: the theme is applied after other mods react to a
  color scheme change, so switching themes no longer loses colors.
- The side gradient of the selected object window is gone too: it uses the
  theme's OverlayTintColor like the other panels (it was a fixed white tint).
- borders.flag (for theme makers): records which controls draw borders and in
  which color.

0.3.0 (2026-11-25)
- Five themes: Amethyst, Basalt (default), Graphite, Obsidian and Synthwave.
- Pick the theme in the DW2 Mod Launcher (UI theme option), or in options.json
  without the launcher: {"Theme": "Basalt"}.
- Themes apply on top of the color scheme chosen in the game's options;
  Colorblind Assist keeps its own warning and status colors.
- In game: Ctrl+Alt+Plus / Ctrl+Alt+Minus switch themes for the session
  (Off included), Ctrl+Alt+0 shows the current theme. The theme name shows
  on screen.
- Switching themes in game also updates buttons, tabs and list selections
  that were already on screen.
- The themes folder is read again on every switch, so an edited theme file
  shows up without restarting the game.
- Panel side gradient removed by the themes (OverlayTintColor).
- Text tooltips use the theme's background; the opaqueTooltips option draws
  them without the panel's transparency.
- Selected object window: tooltip background follows the theme.
- Themes are plain JSON files: any ColorHelper color, plus the static colors
  of UserInterfaceController and EmpireMessage and the SelectionPanel colors.
  Accent shades are derived from AccentColor when a theme leaves them out.
- Theme editor included (theme-editor.html, opens in the browser, offline).
- Log: data\Logs\DW2UIThemes\DW2UIThemes.log

Known limitations
- The side gradient of the selected object window does not come from a color
  and keeps the game's look.
- The system panel at the bottom center and map elements (selection frame,
  icons, population bar) do not follow the theme.
